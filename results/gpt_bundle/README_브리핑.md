**S3b/S4b/S5b/H4b는 전부 같은 체크포인트 파일(`dmd_gen_step1600.pt`, 2000-step 학습 중 1600번째)** 을 쓰고 샘플러 설정만 다릅니다. 즉 이들 사이의 차이는 학습 노이즈가 아니라 순수한 추론 시점 차이입니다.

DMD 학습 설정: generator = ODE회귀 v2 초기화, real score = 동결 teacher(CFG 가이더 유지), fake score = 학습되는 teacher 사본. DMD2식 backward simulation(k∈{0,1,2} 무작위, 마지막 x₀에만 그래디언트). lr_gen 2e-6, lr_critic 4e-7, gen_every 5, AdamW8bit, grad clip 10, batch 1, bf16, 2000 step ≈ 1시간, peak 24.4GB. 체크포인트 선택 = std비(student x₀ std ÷ teacher latent std) ≈ 1.0.

## §5. 평가 정의

- **코드**: `bench_precise_6a.py`(품질), `bench_policy_proxy.py`(영역별 정책 대리), `bench_region_perceptual.py`(영역별 선명도·LPIPS), `bench_timing_final.py`(속도), `bench_qual_package.py`(정성). 전부 GitHub `code/geo4d/`.
- **split·seed**: 추론 에피소드 4개, data_seed 1234로 고정 샘플링, 생성 seed 0(다양성은 0–3). 학습/평가 분리는 Geo4D 원 저장소의 inference 에피소드를 그대로 사용.
- **뷰**: 매 샘플 4개 카메라 중 2개를 무작위 선택(고정 seed) → 왼쪽=참조 프레임, 오른쪽=종속.
- **mask**: (a) 유효 깊이 z>0 (b) **가짜 픽셀 제외** — 오른쪽 GT는 참조 프레임으로 변환될 때 무효 픽셀(xyz=0)이 카메라간 평행이동 t로 바뀌어 z>0을 통과함. |xyz_gt − t| < 2e-3 를 제외(teacher 오른쪽 AbsRel 0.418→0.064). (c) 영역 마스크: 그리퍼 = GT label id 29,30,31,33,34,35 / 물체 = apple 44, cereal 39 / 움직임 = GT 3D가 조건 프레임 대비 >2cm 이동. AbsRel·PSNR은 3px 팽창, 중심오차는 원 마스크.
- **AbsRel** = mean(|z_pred − z_gt| / z_gt), 미터.
- **LPIPS** = AlexNet 백본. 영역별은 spatial=True 맵을 마스크 안에서 평균.
- **선명도** = 회색조 라플라시안 분산. 영역별은 마스크를 1px 침식 후(경계 가짜 에지 제외), 침식 후 200px 미만이면 NaN.
- **다양성** = 시드 4개 간 픽셀별 표준편차의 평균.
- **CV-Chamfer** = 두 뷰 예측 포인트클라우드(둘 다 참조 프레임)의 대칭 chamfer. 스케일 의존적이고 "두 뷰가 같이 틀리면" 좋아지므로 단독 해석 금지.
- **중심오차** = 같은 마스크 안 예측 포인트맵 중심 − GT 중심 [cm].
- **통계**: paired Wilcoxon signed-rank, 90% 신뢰구간은 부트스트랩(4000회) 또는 정규근사. 동등성 판정은 TOST(90% CI ⊂ [−δ,+δ]).
- **주의**: GT 마스크를 예측에 씌우므로 예측 팔이 어긋나면 마스크가 배경을 덮어 중심오차가 부풀려집니다. teacher조차 12cm가 나오는 이유이고, **차이만 해석**해야 합니다.

## §6. 알려진 측정 오류와 정정 기록

1. **오른쪽 뷰 모션 마스크 버그(08-26 수정)**: 오른쪽 GT는 참조 좌표계, 조건 포인트맵은 오른쪽 카메라 좌표계인데 그대로 뺐더니 픽셀의 53%가 "움직임"으로 잡혔습니다. 외부 파라미터 변환으로 수정했으나 **재측정 전** — 현재 영역별 수치는 전부 왼쪽 뷰 20샘플입니다.
2. **20샘플 CI 오판(정정됨)**: 그리퍼 중심오차 +2.0cm [+0.3,+3.7]이 60샘플(n=120)에서 +0.66 [−0.62,+1.94]로 재현되지 않았습니다.
3. **시간 측정 정정**: 초기 25.4초/5.8초는 평가 전용 작업 2.9초를 포함한 값. 순수 추론은 21.49초/1.64초.
4. **정성 이미지 라벨 오류(발표자료)**: `diversity_*1.png`는 1-step 결과인데 3-step 수치와 함께 제시됐었습니다. 3-step으로 재생성 완료.

## §7. 예약된 GPU 작업 (cereal 체크포인트 스윕)

디스크 9.9G 제약 때문에 **구간 학습 → 평가 → 삭제 → 재개** 방식으로 400/800/1200/1600/2000을 순차 확보합니다. 각 체크포인트마다 동일 검증 셋(20샘플)에서 AbsRel·LPIPS·선명도(전체+움직임+그리퍼+물체)·중심오차·다양성을 재고 **샘플별 CSV**를 남깁니다.
- 예상: 학습 1시간 + 체크포인트당 평가 15분 × 5 = 총 약 2시간 15분 (T25 기준선은 이미 측정되어 재사용).
- 선행 실험: step 2000 평가(20분, 디스크 0)로 "학습이 길수록 과선명"인지 먼저 가립니다. GPU가 비는 즉시 자동 시작하도록 걸어둔 상태입니다.
